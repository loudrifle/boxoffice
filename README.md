# boxoffice

A ticketing platform for events: organizers publish events, customers book seats, pay and get their tickets.

It is also my path from frontend developer to backend engineer, built one module at a time.

## Why

I build frontends with React, Next.js and TypeScript. Next.js let me ship full-stack features, but it hides most of what backend engineering is about: databases under concurrent load, background jobs, caching, deployments, observability.

This repo is where I learn those topics properly. Each one gets theory notes, a hands-on lab and a real feature in a project that keeps growing.
